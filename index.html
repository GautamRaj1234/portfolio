Things I've shipped

live flagship project

SmartHire

A full-stack RAG-based resume-screening SaaS. Recruiters upload a resume pool, post a job once, and get every candidate ranked by a hybrid of semantic similarity (Gemini embeddings + ChromaDB vector search) and keyword ATS scoring — with AI-generated skill-gap analysis and interview questions attached to every result.

  • Architected and independently shipped the full stack — FastAPI backend, React frontend — deployed live on Render and Vercel with CI/CD via GitHub Actions.
  • Built role-based access control (recruiter vs. candidate) with JWT auth, enforcing per-user data isolation across every endpoint.
  • Diagnosed and resolved real production failures: CORS misconfiguration, an out-of-memory crash on free-tier hosting, and a breaking third-party model deprecation.
